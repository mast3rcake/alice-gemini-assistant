# Алиса + Gemini + Serper

Персональный голосовой помощник для Яндекс Диалогов. Webhook `/api`, короткие русские ответы, характер с юмором, история в подписанном `session_state`, поиск через Serper по решению Gemini. База данных и Redis не нужны. Опционально отправляет результаты в один фиксированный Telegram-чат и воспроизводит записанное приветствие.

## Быстрый локальный запуск

Нужны Node.js **24.x**, npm и доступ к Google Gemini API из сети компьютера.

```bash
npm ci
npm test
npm start
```

Создайте `.env.local` по шаблону `.env.example` и заполните `GEMINI_API_KEY`. Для поиска добавьте `SERPER_API_KEY`. Сервер: http://127.0.0.1:3000; проверка: `npm run smoke`. Без ключей работают приветствие и проверка протокола. Проверка настоящего Gemini: `npm run smoke -- --live` при запущенном сервере; она использует квоту API.

Подробная инструкция для человека и ChatGPT в режиме «Работа»: [WORK_MODE_SETUP.md](WORK_MODE_SETUP.md).

## Переменные

| Имя | Назначение |
| --- | --- |
| `GEMINI_API_KEY` | Ответы Gemini; обязательна для вопросов |
| `SERPER_API_KEY` | Актуальный поиск; без неё модель получает сообщение о недоступности поиска |
| `TELEGRAM_BOT_TOKEN` | Необязательный токен собственного Telegram-бота |
| `TELEGRAM_CHAT_ID` | Необязательный фиксированный получатель; задавайте вместе с токеном |
| `ALICE_GREETING_AUDIO` | Необязательный ресурс своего навыка `dialogs-upload/<skillID>/<soundID>.opus` |
| `PORT` | Локальный порт, по умолчанию 3000 |

Ключи вводятся локально или в Vercel. Не отправляйте их в чат и не коммитьте `.env.local`. Приветствие использует ресурс **вашего** навыка; звук и ключи автора не включены.

## Vercel и Яндекс

Импортируйте собственный репозиторий в Vercel или выполните `vercel --prod` после входа и привязки к своему проекту. Framework Preset: Other; Node.js 24.x; корень проекта — текущая папка. Настройте Production-переменные и выполните новый deployment. В Яндекс Диалогах укажите `https://<ваш-production-домен>/api`, включите хранение состояния, разрешите голосовую поверхность, протестируйте и опубликуйте навык.

## Поведение и ограничения

Основной обработчик `lib/fast.js` использует `gemini-3.5-flash-lite` и generateContent с минимальным thinking. Доступность модели зависит от Google, региона и квоты; при смене модели сверяйте её настройки с Google. Голосовой бюджет сервера — 3,2 секунды, ответы до 600 символов. История до шести пар сжимается, подписывается ключом Gemini и привязывается к сессии, до 950 байт; между сессиями не сохраняется. Смена ключа делает старые подписи недействительными. Старый Interactions-обработчик оставлен для совместимости тестов и не используется webhook.

Telegram включается только по явной команде отправки. Алиса подтверждает приём; генерация и отправка продолжаются в фоне. Пример: «Составь список покупок для пасты и пришли в телеграм». Реальная доставка проверяется в Telegram, подтверждение приёма её не гарантирует. На Vercel используется waitUntil; локально процесс должен оставаться запущенным. Общей очереди и гарантии доставки нет, дедупликация действует только в одном экземпляре.

Webhook публичен. Подпись состояния не аутентифицирует запросы. Это персональный помощник с одним получателем Telegram: доступ к webhook может расходовать квоту и инициировать отправку в этот чат. Для общедоступного навыка с несколькими пользователями нужна отдельная привязка получателей. Тексты запросов передаются Google, поисковые запросы Serper, явно отправляемые результаты Telegram. В логах только технические метаданные.

Локальный сервер слушает только 127.0.0.1. Яндекс не может вызвать localhost: для колонки нужен публичный HTTPS-сервер, например Vercel. ChatGPT в облачной среде может подготовить и протестировать проект в своей среде, но доступ к компьютеру пользователя зависит от доступных инструментов.
